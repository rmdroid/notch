What exactly is TermNotch?+

TermNotch is a native terminal for macOS. A keyboard shortcut opens it at the notch or the top of your screen. Use it to run terminal commands and installed CLI tools.

Are Claude Code or Codex included?+

No. TermNotch provides the terminal. Install and configure Claude Code, Codex CLI and other tools separately. Their accounts, subscriptions or API costs are not included.

Do I need a MacBook with a notch?+

TermNotch is optimized for MacBooks with a notch. On Macs without one, the terminal appears at the top center of the screen. macOS 15 or later is required.

Can I choose my own shortcut?+

Yes. The default is Ctrl + I. You can change the modifier keys and key in settings.

Is this a subscription?+

No. TermNotch is a one-time purchase of €9.99*. All updates are included. See the pricing section for payment details.

Does the app run locally?+

TermNotch runs locally on your Mac, is Apple signed and notarized, and uses no telemetry. The AI tools you launch may need an internet connection and use their own services.

What can the local API do?+

Through HTTP on port 7777, other tools can show or hide the terminal, start commands, address tabs and display notifications.
